Without a connection, Jarvis can answer a few built-in commands. To get generated AI replies, enter an OpenAI-compatible API endpoint and credentials from a provider. Free availability depends on that provider.

Only connect to a provider you trust. Your messages and key are sent to that endpoint; browser storage is not encrypted. Don’t use a sensitive key on a shared device.

Voice features depend on your browser. Use Chrome on Android and allow microphone access.
